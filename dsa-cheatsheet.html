↔️ Two Pointers

When: sorted array/string, pair/triplet sums, palindrome, in-place partition, remove duplicates.
  • Opposite ends: move the pointer that can improve the answer.
  • Same direction: slow = write index, fast = read index.
  • Sort first if order doesn't matter; skip duplicates for k-sum.
def two_sum_sorted(a, target):
    l, r = 0, len(a)-1
    while l < r:
        s = a[l] + a[r]
        if s == target: return (l, r)
        if s < target: l += 1     # need bigger
        else:          r -= 1     # need smaller
Opposite ends (sum):
  [ 2  3  5  8  11 ]  target=13
    l -->        <-- r
  a[l]+a[r]=13  -> found

Same direction (dedupe):
  [1,1,2,3,3]
   s        (write)
      f      (read, skip dupes)

🪟 Sliding Window

When: longest/shortest/count of contiguous subarray/substring satisfying a constraint.
  • Grow with right; shrink from left while invalid.
  • Track window state: sum, or char-frequency map.
  • Fixed size k → add r, remove r-k.
def longest_valid(s):
    cnt, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        cnt[ch] = cnt.get(ch,0)+1
        while invalid(cnt):        # e.g. dup found
            cnt[s[left]] -= 1
            left += 1
        best = max(best, right-left+1)
    return best
  a b c a b c b b
  [.....]              window grows ->
      [.....]          shrink left when a char repeats
  best = max window length while valid

🔍 Binary Search

When: sorted search space OR the answer is monotonic (feasible-then-infeasible). "Minimize/maximize X such that check(X)".
  • Classic: while lo <= hi, compare a[mid].
  • On answer: binary search the value; write a monotone feasible(x).
  • Rotated array: one half is always sorted — check which.
def bs_on_answer(lo, hi, feasible):
    # smallest x with feasible(x) == True
    while lo < hi:
        mid = (lo + hi) // 2
        if feasible(mid): hi = mid
        else:             lo = mid + 1
    return lo

                     ^ answer (first True)
lo ----------> | <---------- hi
        collapse toward boundary

📚 Stack & Monotonic Stack

When: matching/parentheses, "next greater/smaller", histogram spans, undo.
  • Monotonic: pop while top breaks the order — that pop is resolved by current element.
  • Next Greater → decreasing stack of indices.
def next_greater(a):
    res = [-1]*len(a); st = []          # indices, decreasing
    for i, x in enumerate(a):
        while st and a[st[-1]] < x:
            res[st.pop()] = x
        st.append(i)
    return res
a = [2, 1, 3]
stack(idx): [0] -> [0,1] -> pop 1,0 (both<3)
NGE:          2->3, 1->3, 3->-1

🔗 Linked List

When: pointer manipulation. Tools: dummy head, fast/slow, iterative reverse.
def reverse(head):
    prev = None
    while head:
        nxt = head.next
        head.next = prev
        prev = head
        head = nxt
    return prev

# fast/slow: middle & cycle
slow = fast = head
while fast and fast.next:
    slow = slow.next; fast = fast.next.next

🌿 Recursion & Backtracking

When: generate all subsets/permutations/combinations, grid paths, constraint puzzles (N-Queens, Sudoku).
  • Template: choose → explore → un-choose.
  • Combos use a start index; perms use a used[].
  • Sort to skip duplicates; prune early.
def backtrack(path, choices):
    if is_goal(path):
        res.append(path[:]); return
    for i, c in enumerate(choices):
        path.append(c)                 # choose
        backtrack(path, next(choices,i))# explore
        path.pop()                     # un-choose

⛰️ Heap / Priority Queue

When: "Top-K", "Kth largest/smallest", "median of stream", "merge k sorted".
  • Python heapq = min-heap; push -x for max-heap.
  • Kth largest: min-heap of size k → root is answer.
  • Median: two heaps (max-heap low half, min-heap high half).
import heapq
def kth_largest(nums, k):
    h = []
    for x in nums:
        heapq.heappush(h, x)
        if len(h) > k: heapq.heappop(h)
    return h[0]                # size-k min-heap
Two-heap median:
  maxHeap(low)      minHeap(high)
   [3 2 1]   <-->    [4 5 6]
     top=3            top=4
  median = (3+4)/2 or top of larger heap

🕸️ Graphs

When: connectivity, paths, cycles, ordering. BFS = fewest edges; DFS = explore/cycle/topo.
from collections import deque
def bfs(start, adj):
    seen = {start}; q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in seen:
                seen.add(v); q.append(v)

import heapq                    # Dijkstra (non-neg weights)
def dijkstra(src, adj, n):
    dist = [float('inf')]*n; dist[src]=0
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue
        for v, w in adj[u]:
            if d+w < dist[v]:
                dist[v]=d+w; heapq.heappush(pq,(dist[v],v))
    return dist
  • Topo sort (Kahn): repeatedly remove 0 in-degree nodes.
  • Cycle (directed): DFS 3-color OR topo fails.
  • Union-Find: connectivity / MST (Kruskal).
parent = list(range(n))
def find(x):
    while parent[x]!=x:
        parent[x]=parent[parent[x]]   # path compress
        x=parent[x]
    return x
def union(a,b): parent[find(a)] = find(b)
Grid = graph: neighbors = up/down/left/right; use multi-source BFS for "spread" problems.

🔤 Trie (Prefix Tree)

When: many prefix / word lookups, autocomplete, max-XOR (bitwise trie).
class Trie:
    def __init__(self): self.root = {}
    def insert(self, w):
        node = self.root
        for c in w: node = node.setdefault(c, {})
        node['$'] = True            # end marker
    def search(self, w, prefix=False):
        node = self.root
        for c in w:
            if c not in node: return False
            node = node[c]
        return True if prefix else '$' in node

🧮 Dynamic Programming

When: overlapping subproblems + optimal substructure. "count ways / min-max / can we".
  • Steps: define state → transition → base case → order.
  • Write recursion + memo first, then convert to tabulation.
  • Common states: index, (i,j) two seqs, (index, capacity), bitmask.
from functools import lru_cache
@lru_cache(None)
def solve(i, cap):              # top-down memo
    if i == n or cap == 0: return 0
    skip = solve(i+1, cap)
    take = 0
    if wt[i] <= cap:
        take = val[i] + solve(i+1, cap-wt[i])
    return max(skip, take)

🎯 Greedy

When: local optimum → global optimum (must argue it). Usually sort first.
  • Intervals: sort by end; take earliest-finishing that fits (non-overlap / min removals / arrows).
  • Scheduling/profit: sort + heap; pick best available now.
  • Jump game: track farthest reachable index.
  • If greedy is hard to prove → suspect DP instead.

🔟 Bit Manipulation

  • x & 1 → last bit; x >> 1 → divide by 2.
  • x & (x-1) → clears lowest set bit (count bits).
  • a ^ a = 0, a ^ 0 = a → XOR cancels pairs.
  • x & -x → isolates lowest set bit (Fenwick).
Single number (all pairs but one):
  XOR everything -> pairs cancel -> answer

Subsets via bits (n items):
  for mask in range(1<<n):
     pick i if mask & (1<<i)

✅ Interview Playbook

  • 1. Clarify — input ranges, dups, sorted?, empty/edge cases, expected complexity.
  • 2. Brute force first — state it, give its complexity, then optimize.
  • 3. Match a pattern — sorted? → two-ptr/BS. Contiguous? → window. Top-K? → heap. Overlapping subproblems? → DP.
  • 4. Think out loud — narrate the approach before coding.
  • 5. Dry-run a small example after coding; check edge cases (empty, 1 element, all same, overflow).
  • 6. State complexity — time & space, and any trade-offs.
